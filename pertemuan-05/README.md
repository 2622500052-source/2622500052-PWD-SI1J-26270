P5 JavaScript Dasar, DOM, Event, dan Validasi Sisi Klien
Deskripsi
Dokumentasi pengembangan halaman web pada P5, meliputi JavaScript, DOM, event listener, interaksi navigasi, dan validasi formulir sisi klien.

Fitur dan Pengembangan
Interaksi Navigasi Responsif: Menambahkan tombol hamburger dan manipulasi class DOM.
Validasi Formulir: Menambahkan pemeriksaan input nama, email, semester, tanggal, jenis pesan, minat, prodi, dan pesan.
Pengujian
Tombol navigasi dapat membuka dan menutup menu pada layar seluler.
Formulir menampilkan pesan error jika ada input kosong/salah dan pesan sukses jika semua valid.
Riwayat Pengembangan
Siapkan baseline P5 dari P4.
Tambahkan berkas script.js dan README.md.
